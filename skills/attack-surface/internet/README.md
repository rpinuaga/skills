# Internet Attack Discovery

External attack surface that lives directly on the internet, split into three
asset classes:

| Leaf skill (black-box) | Leaf skill (white-box) | Scope |
| ---------------------- | ---------------------- | ----- |
| `ip-blackbox`          | `ip-whitebox`          | IP space, ranges, ASNs, origins, open ports |
| `dns-blackbox`         | `dns-whitebox`         | DNS records, hostnames, subdomains, zones |
| `email-blackbox`       | `email-whitebox`       | Email authentication, MX, senders, ESPs |

Human navigation only — the skills are the `SKILL.md` leaf directories.
